# نصب فونت‌های self-hosted

## ۱. Vazirmatn
1. از این آدرس دانلود کن: https://github.com/rastikerdar/vazirmatn/releases
2. آخرین نسخه `vazirmatn-vXX.XX.zip` را بگیر
3. سه فایل زیر را استخراج کن به پوشه‌ی `vazirmatn/`:
   - `Vazirmatn-Regular.woff2`
   - `Vazirmatn-Bold.woff2`
   - `Vazirmatn-Black.woff2`

## ۲. Sahel (اختیاری — برای عنوان‌ها)
1. از این آدرس: https://github.com/rastikerdar/sahel-font
2. فایل‌های `.woff2` را در پوشه‌ی `sahel/` بگذار
